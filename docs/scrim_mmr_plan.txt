# 내전 MMR 체계 개편 계획

## 변경 배경
- 현재 티어 간격 200점, 판당 변동 최대 ±10으로 격차가 너무 작음
- 231경기 후에도 상위~하위 MMR 차이가 1500점에 불과
- 티어 승급에 의미감이 부족하여 체계 전면 개편 결정

---

## 1. 새 티어 구조 (500점 간격)

| 티어       | MMR 범위      |
|------------|---------------|
| 브론즈     | 0 ~ 499       |
| 실버       | 500 ~ 999     |
| 골드       | 1000 ~ 1499   |
| 플래티넘   | 1500 ~ 1999   |
| 에메랄드   | 2000 ~ 2499   |
| 다이아     | 2500 ~ 2999   |
| 마스터     | 3000+         |

---

## 2. 1판 MMR 변동 (방안2: 승패 고정 + 순위 보너스)

- 승리팀 기본 +20, 패배팀 기본 -20
- 팀 내 MVP 순위 보너스: 1등 +8 / 2등 +4 / 3등 0 / 4등 -4 / 5등 -8

| 순위 | 승리 최종 | 패배 최종 |
|------|-----------|-----------|
| 1등  | +28       | -12       |
| 2등  | +24       | -16       |
| 3등  | +20       | -20       |
| 4등  | +16       | -24       |
| 5등  | +12       | -28       |

### 설계 근거
- 60% 승률 30판 기준 한 티어(500점) 상승 목표 (롤 실버→골드 약 30판 기준)
- 잘하면 져도 -12로 방어 가능, 못하면 이겨도 +12만 획득 → 개인 퍼포먼스 반영

---

## 3. 기존 데이터 마이그레이션

### 방법
기존 내전 MMR을 2.5배 스케일 변환 (티어 위치 유지, 상대 순위 보존)

```sql
UPDATE scrim_ratings SET mmr = ROUND(mmr * 2.5);
```

### 변환 예시
| 닉네임   | 현재 MMR | 변환 후 MMR | 티어     |
|----------|----------|-------------|----------|
| 기 류    | 1600     | 4000        | 마스터   |
| 중위권   | 800      | 2000        | 에메랄드 |
| 하위권   | 400      | 1000        | 골드     |

- scrim_mmr_logs 과거 기록은 변경하지 않음 (참고용 보존)

---

## 4. 코드 수정 목록

1. lib/scrim.ts
   - mmrToScrimTier() 구간 변경 (200 간격 → 500 간격)
   - soloBadgeToInitialMmr() 초기값 × 2.5 반영
   - SCRIM_MMR_DELTA 변경: [10,5,0,-5,-10] → [8,4,0,-4,-8]

2. app/api/scrim/match/resync/route.ts
   - MMR delta 계산 로직 변경
   - 승리 기본 +20 / 패배 기본 -20 추가
   - 순위 보너스 [8,4,0,-4,-8] 적용

3. DB 마이그레이션 실행
   - UPDATE scrim_ratings SET mmr = ROUND(mmr * 2.5);

## 5. 팀 생성 수치 변경 (app/api/scrim/balance/route.ts)

현재 → 변경 (모두 × 2.5)

| 항목                  | 현재  | 변경  | 설명                                      |
|-----------------------|-------|-------|-------------------------------------------|
| tolerance             | 200   | 300   | 두 팀 합산 점수 차이 허용 범위            |
| 라인 보정 (ALL/미지정) | -150  | -375  | 주라인 아닌 라인 배정 시 패널티           |
| 라인 보정 (명시 부라인) | -300  | -750  | 명시적 부라인 아닌 라인 배정 시 패널티    |
| 팀1 가산점            | +50   | +125  | 팀1 합산에 더해서 균형 보정               |

## 6. 미결 사항

- MMR 하한선 설정 여부 (0점 이하 방지 → 현재 GREATEST(0, mmr+delta) 로직 유지 예정)
- 서폿 MVP 가중치 별도 적용 여부 (현재는 전 라인 동일 가중치)
