================================================================
                    클랜 매니저 기능 설명
================================================================

----------------------------------------------------------------
1. 클랜원 관리 (/userInfo)
----------------------------------------------------------------
- 클랜원 전체 목록 조회 (티어, 라인, 포지션, 상태 표시)
- 클랜원 정보 수정 (생년월일, 성별, 메인/서브 라인, 상태메모)
- 롤 계정 연동/추가/삭제, 본계정 설정
- 계정 전적 동기화 (Riot API)
- 경고 부여/조회
- 수습 전용 테이블: 파티참여 O/X 표시, 3판 달성 시 클랜원 전환 버튼
- 클랜원 삭제, 비밀번호 초기화

----------------------------------------------------------------
2. 파티 (/party)
----------------------------------------------------------------
- 모드별 파티 생성 (칼바람 / 일반 / 자유랭크 / 솔로랭크)
- 참가자 명단 수정
- 파티 펑 시 자동 포인트 지급:
  - 칼바람: 판수 입력 → 기준 달성 시 포인트
  - 협곡: Riot API로 실제 전적 조회 → 파티원과 함께한 판수 기준
  - 수습 동반 시 +10점 보너스
  - 수습 본인: 파티참여 횟수 기록 (points=0)
- 같은 날 중복 지급 방지

----------------------------------------------------------------
3. 내전 (/scrim)
----------------------------------------------------------------
- 내전 모집 공고 생성/신청/취소
- 팀 구성 후 내전 경기 기록 (KDA, 챔피언, 딜량)
- 경기 결과 저장 및 조회

----------------------------------------------------------------
4. 포인트 (/points)
----------------------------------------------------------------
- 클랜원별 포인트 적립 내역 조회
- 타입별 표시: 칼바람 / 자유랭크 / 솔로 / 일반 / 수습 / 수동지급 등
- 실제 게임 판수 함께 표시

----------------------------------------------------------------
5. 소환사 검색 (/search)
----------------------------------------------------------------
- Riot ID(닉네임#태그)로 소환사 검색
- 최근 매치 히스토리, 랭크 티어 조회

----------------------------------------------------------------
6. 친구 (/friends)
----------------------------------------------------------------
- 클랜원 간 친구 관계 등록/조회
- 함께 플레이한 기록 기반

----------------------------------------------------------------
7. 계정/인증
----------------------------------------------------------------
- 로그인/로그아웃
- 회원가입 (운영진이 클랜원과 연동)
- 비밀번호 변경
- 역할: admin / subadmin / member

================================================================
